ABOUT

はじめまして。Ishizuka-Tです。Web系のシステム開発を中心に、主にRuby on Railsを用いた業務アプリケーションの開発に携わってきました。
要件定義から設計・実装・テストまで、開発工程を一通り経験しています。
チームでの開発や、お客様の声をもとにした改善提案にも積極的に取り組んできました。
技術だけでなく、ユーザーやメンバーとの対話を重視した開発を心がけています。
今後は、よりユーザー視点を活かした「価値あるシステムづくり」に貢献していきたいと考えています。どうぞよろしくお願いします。

SKILL

Ruby/Ruby on Rails

Rubyは読みやすく書きやすいプログラミング言語で、Webアプリ開発向けのフレームワーク「Ruby on Rails」を用いた実務経験があります。 （RubyはJava、RailsはSpring Bootに近い位置づけの技術です）

HTML/CSS

HTML/CSSを用いたページのコーディングが可能です。レスポンシブ対応やレイアウト調整も経験があります。

JavaScript/jQuery

JavaScriptおよびjQueryを使い、ユーザー操作に応じた動的なUIや処理を実装できます。

MySQL

MySQLを用いたデータ抽出や集計、テーブル設計の経験があります。業務データの分析やバックエンド連携で活用してきました。

Linux

Linux環境での基本的な操作やコマンドによる作業に対応できます。開発環境の構築や簡単なトラブル対応の経験があります。

Git/GitHub

Gitを用いた開発フローに沿って、適切なコミットメッセージやブランチ運用を心がけています。GitHubでのコードレビュー対応も経験しています。

AWS

AWSではCloudWatchを使ったログ監視や、IAMユーザーの作成・権限設定など基本的な運用管理を経験しています。必要な範囲でサービスを調査・活用しています。

WordPress

WordPressを用いたマニュアルサイトの構築・運用・投稿管理を経験しています。

PERSONALITY

回復志向

課題を見つけて、改善していくことが得意です。トラブルが起きても、冷静に原因を分析して立て直せます。

個別化

相手の性格や強みに応じて、柔軟に対応するのが得意です。型にはめずに、その人に合った関わり方を大切にしています。

親密性

信頼関係を大切にしながら、長く深く人と関わるのが得意です。関係を大切にし、相手に寄り添いながら仕事を進めます。

慎重さ

物事を始める前にしっかりとリスクを見極めるタイプです。トラブルを未然に防ぐよう意識しています。

着想

他の人が気づかないようなつながりや可能性を見つけて、チームに刺激や発見を与える役割をしてきました。
